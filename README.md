# sinc-interpolation-nyquist-demo
Simulates sampling a two-tone signal above, at, and below the Nyquist rate, then reconstructs it via Whittaker–Shannon sinc interpolation — with time- and frequency-domain plots showing oversampling fidelity vs. aliasing distortion.
A couple of alternates if you want something shorter or punchier:
two-tone-sampling-demo — "Sinc reconstruction of a sampled two-tone signal, visualizing aliasing below the Nyquist rate."
nyquist-aliasing-sim — "Python/NumPy simulation comparing sampling rates relative to Nyquist and their effect on sinc-based signal reconstruction."
